# Glossary

**_can_see** — gate: enemy on screen in x/y and not far below Frank ([[ch07-enemies-ai|ch07]])
**_same_floor** — gate: enemy acts only on Frank's floor, FLOOR_REACH 400 ([[ch07-enemies-ai|ch07]])
**art_src** — numbered Gemini originals on the PC ([[ch03-art-pipeline|ch03]])
**ashes_reports** — Supabase table with crash/error reports ([[ch04-phone-memory|ch04]])
**Basis** — compressed GPU texture format for streets/rooms; never for CPU-read art ([[ch03-art-pipeline|ch03]], [[ch04-phone-memory|ch04]])
**BigTex** — loader reporting painted size for capped/half-size imports ([[ch03-art-pipeline|ch03]])
**boss_room** — level key for boss arenas: club, office ([[ch05-levels-maps|ch05]])
**crumbs** — breadcrumbs in localStorage `ashes_crumbs` ([[ch04-phone-memory|ch04]])
**CURVE** — difficulty table in main.gd, map by map ([[ch07-enemies-ai|ch07]])
**DEEP_SPLIT** — deep street views that slide as flat planes ([[ch05-levels-maps|ch05]])
**FIG** — figure scale 1.18 ([[ch08-player-progression|ch08]])
**FIRE_SPOTS / FIRES** — measured fire positions in drawings ([[ch06-lights-fx|ch06]])
**give** — enemy state: surrendered ([[ch07-enemies-ai|ch07]])
**guilt / ash** — moral system from executions vs letting men go; endings Snow / Ash ([[ch07-enemies-ai|ch07]], [[ch10-story-cutscenes|ch10]])
**[[HANDOFF|HANDOFF.md]]** — session log in repo root (SKILL.md)
**Instincts** — perk system: XP levels, points, rows FRANK/GUN/TRICKS ([[ch08-player-progression|ch08]])
**KIT / SEGMENT_KIT** — base street drawings and their variants ([[ch03-art-pipeline|ch03]])
**KITS (levels.py)** — upper-floor kits "roof", "mezz" ([[ch05-levels-maps|ch05]])
**LIVE** — live fire/smoke spots per cutscene panel ([[ch10-story-cutscenes|ch10]])
**LowRes** — wrapper for half-size art, reports full size ([[ch03-art-pipeline|ch03]])
**mapfx** — per-map dynamic features (el, fog, storm, flood…) ([[ch05-levels-maps|ch05]])
**packs a/b/c** — per-chapter resource packs (prologue+I / II / III) ([[ch04-phone-memory|ch04]])
**Paper** — paper UI kit, `Paper.audit()` → `UI BAD` ([[ch11-ui-hud|ch11]])
**puppet** — character built from parts, posed by code ([[ch08-player-progression|ch08]])
**ROOM_BULBS / ROOM_PENDANTS** — shootable painted bulbs / swinging lamps ([[ch06-lights-fx|ch06]])
**SEGMENT_LIGHTS** — lamp positions per street drawing ([[ch06-lights-fx|ch06]])
**SEG_SIZE** — drawing scale per segment family (metro SUB 0.52) ([[ch05-levels-maps|ch05]])
**setpieces** — scripted events: trains, cranes, searchlights ([[ch05-levels-maps|ch05]])
**slowed time** — bullet time; stopwatch button ([[ch08-player-progression|ch08]])
**SMITH_PARTS** — gunsmith upgrade hotspots ([[ch08-player-progression|ch08]])
**TRACKLESS** — segments where no train may pass ([[ch05-levels-maps|ch05]])
**UI BAD** — audit failure line; must never appear ([[ch02-tests|ch02]], [[ch11-ui-hud|ch11]])
**úskok** — the dive move's Czech UI name ([[ch08-player-progression|ch08]])
